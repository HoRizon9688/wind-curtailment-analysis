# 每日访问口令：本地验收设计

用户已确认每日六位口令方案，并要求新分支开发、本地验收后再部署。分支为 `codex/daily-access-token`，基线 `e737c5a`。本轮不推送 main、不部署、不改变 GitHub Pages、Sites 分享权限或计算算法。

北京时间每日00:00切换口令。口令由服务端高熵密钥与日期通过HMAC生成，补齐六位数字。登录后使用独立密钥签名的HttpOnly、Secure、SameSite=Lax Cookie；当天结束失效，修改任一密钥可使相关口令或会话失效。密钥不进入网页、代码仓库、URL或日志。本机命令提供管理员取码方式。

所有应用文件先鉴权再返回，包含HTML、样例、别名和条件请求。缺少密钥、限流或资产配置时拒绝放行。登录/退出POST验证同源Origin，拒绝过大请求、不回显口令；登录错误与限流分别明确提示。Cookie使用主机限定前缀，不接受伪造、篡改、跨日或超长值。口令属于共享准入凭证，不识别个人，不保证阻止已下载代码离线使用。

Cloudflare使用Workers Static Assets与原生限流绑定。Sites已有平台身份验证继续生效；其公开配置只明确支持D1/R2，因而为Sites提供D1限流适配和独立Worker构建，以免使用实例内计数冒充可靠限流。口令/会话本身不依赖数据库。Sites部署时才创建/绑定该独立限流表，不触碰计算数据；本轮仅本机模拟验证。

登录页沿用Scientific blue的浅蓝背景、深蓝文字、蓝色描边及圆角，支持亮暗切换。使用单个可粘贴的六位输入框、显示/隐藏按钮、加载反馈与字段旁错误提示；窄屏纵向布局，不使用外部字体或服务。

本机开发使用独立端口和仅本地生成的密钥。验证覆盖日期边界、取码、Cookie签名/过期、跨源请求、限流、异常关闭、直接资产绕过、登录/退出、实际上传计算、移动布局与主题。当前公开静态发布文件保持字节不变。未授权部署前不写入Cloudflare或Sites环境变量。
