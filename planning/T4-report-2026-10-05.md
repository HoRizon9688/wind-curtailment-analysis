## 1. 实现与接入接口

新增模块位于 `dashboard/src/content/calculation/`：

- `calculation.worker.mjs`：只调用同一 `analyzeFiles`，顺序完成解析、分类和汇总；不复制公式。
- `calculation-client.mjs`：独立任务 ID、旧任务隔离、terminate 取消、错误和结束释放。每次 start 新建 Worker，开始新任务会终止旧任务；dispose 后禁止重新启动。
- `calculation-browser.mjs`：浏览器公共入口，以 `?worker&inline` 绑定真实 Worker 构造器，支持仓库子路径。底层客户端的 workerFactory 仅用于可测的传输边界。
- `worker-errors.mjs`：只传递契约允许的 code/message/file/row/field，不返回 Error 内部属性；创建、执行、传输和协议错误均可终止并重试，不替换成零电量。
- `result-transfer.mjs`：大结果分批传回，完整装配后才触发成功回调。

`analyzeFiles(input,onProgress)` 和 `analyzeNormalized(normalized,options,onProgress)` 增加可选进度回调。读取以完成文件数计，完成读取包括原字节 SHA-256；校验以整个标准化步骤 0/1 计；计算以完成分钟数计，每日发一次更新；汇总以日汇总、整期汇总、calibration 和缺失区间的实际步骤计。没有定时器伪造百分比。汇总完成仍需传回数据，只有 result 完整接收才代表任务成功。

输入 ArrayBuffer 被 transfer 后会变为零长度，客户端不保留 input 或原始字节。取消/结束移除事件处理器、清空部分结果并 terminate Worker。重试必须从用户选中的 File **重新读取 ArrayBuffer**，不能复用已转移缓冲。源计算的输入/标准化数据不被修改；解析表格在标准化后释放数组引用。

T5 接入示意：

```js
import {createCalculationClient} from '../calculation/calculation-browser.mjs';
const client=createCalculationClient({onProgress,onResult,onError});
// 每次计算前重新 await file.arrayBuffer()，再创建 Input。
const requestId=client.start(input);
client.cancel(); // 用户取消，或新计算前由 start 自动取消旧任务
client.dispose(); // 页面组件卸载
```

成功/错误回调均带 requestId。客户端只报告事件，不持有“上次成功分析”；T5 负责成功前保留原分析及表单草稿。取消不会调用 onResult/onError，调用方同步更新自己的取消状态。

## 2. 性能证据与协议裁决

先测完整主线程算法，15/31 天分别出现 **462/741 ms** 长任务；不是 T0 的顺序遍历代理。由此核定启用 Worker，符合先测量要求。

第一次 Worker 年度测试虽计算完整，但一次性 structured clone 527,040 行导致 **2,858/2,638 ms** 主线程长任务。仅“放进 Worker”不足以保证交互响应。

协调者据实测核定内部协议扩展：结果超过 4096 行时发送 `result-part`，每批最多 1024 行，包含 offset、totalRows 和 requestId；终包包含 rowCount 与空 rows 的结果头。客户端验证连续偏移、总量、批次上限与完整性，装配全部 rows 后才提交一次完整六字段 Result。缺片/重复/乱序/超量报 INTERNAL；取消或过期片段不提交并释放。Worker 在已发送批次后释放对应行引用。小结果保持完整消息。

公开 Input、Result、Progress、Error 和容差没有改变。扩展已记入 `docs/browser-calculation-contract.md` 和执行计划，不是偷偷裁剪结果、改算法或放宽比较器。最终校核字段仍只供内部分析，不添加网页面板。

代表性图表呈现使用现有 `wind-model` 的 stepPath/bands 构建首日四条曲线与分类阴影，并等待实际浏览器绘制帧。**不是整个业务 Dashboard 的 React/来源/导出验收**，该项仍留 T5。没有为了性能删除分钟、来源、状态或校核字段。

额外独立页面加载测量：同一合成测试页面首次 loadEventEnd **59.1 ms**，刷新后 **12.9 ms**；程序模块首次传输 120,631 字节，缓存重载 transferSize=0。缓存只用于 JS 程序，合成输入和结果页 no-store。这是 loopback 下的程序测试页，不是公网带宽测量或最终网页加载承诺。

内存是 **采样到的 JS heap**，不是总进程 RSS，也不是精确峰值保证。年度 Worker 最大样本约 **1.095 GB**，主线程约 **0.653 GB**，Worker backing storage 最大样本约 51.7 MB；各自峰值不能直接相加当同一时刻总量。31 天 CSV Worker 约 106.8 MB、日期 XLSX 约 110.6 MB。保留 1—366 天边界，但年度完整结果确实需要较高内存；手机、低内存设备、其他浏览器及年度巨型 OOXML 未在本轮验证。
