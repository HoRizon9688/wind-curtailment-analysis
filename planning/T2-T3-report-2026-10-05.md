## 2. 实现与必要受保护改动

计算模块位于 `dashboard/src/content/calculation`：`scalar`、`time`、`input-model`、`interpolation`、`threshold-allocator`、`aggregate`、`analyze` 和结构化 `errors`。异步 `analyzeFiles` 负责读取；同步 `analyzeNormalized` 接收标准化 Map。容量来自输入，来源哈希覆盖原文件字节；无 API、文件系统或页面存储调用。

- 预测版本 +15 分钟为第二点目标；连续节点线性插值，精确节点优先，不跨缺点、不外推。
- 全日分钟网格、跨日延续状态、排除后 reset，负实发整分钟排除；能量仅除以 60 一次。
- 严格保留六个顶层 Result 字段及条件字段，不将不存在的字段补 null；保留原因、布尔状态、来源、日汇总、半开缺失区间和内部 calibration。
- 避免对年度分钟键使用参数展开求 min/max；366 天实际输出 527,040 个分钟，没有截断结果。
- T1 日期缺陷通过 `excel-dates.mjs` 窄适配修复：公开读取库仍决定单元格类型/样式/缓存值，仅从选中工作表原始数字序列恢复日期，以 Python 毫秒舍入规则校正。真实非零秒/毫秒继续拒绝，不统一取整到分钟。只有时刻没有日期的单元格保持 Python time 的字符串语义并被时间校验拒绝。
- SAX 元数据读取支持命名空间、单引号、实体、活动工作表与 1900/1904 日期系统；沿用原有 60 MB 输入和 150 MB 实际解压限额、中央目录分配提示限制。

窄适配直接使用读取库依赖树中**已锁定**的 `saxen@11.2.0` 公共 Parser。为避免隐式依赖提升，新增明确直接依赖声明。必要受保护路径仅 `dashboard/package.json`、`dashboard/package-lock.json`，已按 AGENTS 官方授权命令精确列出这两个 scope；`protected-runtime.json` 由官方命令更新对应两项哈希。没有手工重签、改变其他依赖版本/完整性、修改 node_modules 或壳层。离线 package-lock-only 命令因 npm 元数据未缓存失败后，只补齐已锁定版本的根依赖声明，未安装新版本。
